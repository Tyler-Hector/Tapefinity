# Tapefinity
Machine Learning algorithm for Tapefinity device
I will be using a human walking acceloration dataset to train a Recurrent Neural Network (RNN) Machine Learning algorithm which will then be used to develop a continous algebraic function the 50 scattered 
dots coming from the 2 input (time and measurement) and 1 output (actual measurment) graph. I will then augment the data in numerous different ways to ensure I have enough files to test with and it will then
search for a pattern for how off Tapefinity is and develop a simple mathmatical model to describe it which will then be encoded into the Nano.
